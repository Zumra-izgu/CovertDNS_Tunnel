CovertDNS_Tunnel Encryption Package

This package provides cryptographic primitives for the CovertDNS system:
    - AES-256-GCM authenticated encryption
    - Kyber-768 (ML-KEM) post-quantum key encapsulation
    - Hybrid cryptography (Kyber + AES)

NIST Standards:
    - ML-KEM (Kyber-768): FIPS 203
    - AES-256-GCM: NIST SP 800-38D
